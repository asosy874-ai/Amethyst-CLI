# Amethyst-CLI
Lightweight terminal music player written in Python. Features high-resolution cover art via Kitty Graphics Protocol, real-time synced lyrics, MPRIS desktop integration, and automatic playlist import.

Quick Install & Testing

1. Clone the repository:
git clone https://github.com/asosy874-ai/Amethyst-CLI/
cd Amethyst-CLI
3. Run the automated installer (sets up an isolated .venv and links Amethyst to ~/.local/bin):
chmod +x install.sh
./install.sh
4. Launch from anywhere:
Amethyst
